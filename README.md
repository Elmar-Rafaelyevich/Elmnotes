# LectureBot 📚

**LectureBot** — это Telegram-бот для студентов, который преобразует текст и аудио в конспекты лекций в форматах TXT и DOCX. Идеальный помощник в учёбе для организации и управления учебными материалами.

---

## Возможности

- 🎙 **Преобразование аудио в текст** — загрузи аудиозапись лекции, и бот автоматически её расшифрует
- 📝 **Преобразование текста в конспекты** — отправь текст, получи структурированный конспект
- 💾 **Сохранение в TXT или DOCX** — выбирай удобный формат для заметок
- 🤖 **Простое взаимодействие через Telegram** — интуитивно понятные команды
- 🔄 **Автоматическая генерация расшифровок лекций** — экономия времени на конспектировании
